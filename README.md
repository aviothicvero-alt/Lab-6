# Lab-6
Overview
This lab focuses on data privacy, security, and risk mitigation when using Generative AI tools in aviation management. It provides a structured audit process for identifying, redacting, and replacing Personally Identifiable Information (PII) and confidential operational data with safe placeholders before drafting customer and internal communications.

Key Highlights
PII & Data Sensitivity Classification: Categorizes aviation data across sensitivity levels (Public, Internal, Confidential, Restricted/Highly Sensitive) to determine what can safely be processed by public GenAI models.

Data Minimization: Emphasizes stripping out non-essential details (e.g., passports, national ID numbers like Aadhaar, full payment details, and medical info) and retaining only the bare minimum needed for drafting content.

Safe Prompt Engineering: Demonstrates how replacing real identities with placeholders (such as [PASSENGER NAME] or [BOOKING REFERENCE]) allows AI to generate clear, professional drafts without exposing sensitive personal data.

Preventing Unsupported Commitments: Outlines instructions to prevent GenAI from hallucinating or committing to unverified delivery timelines or financial compensation claims, substituting them with placeholders like [VERIFY AIRLINE POLICY].

Human-in-the-Loop Verification: Reaffirms that all AI-generated outputs must undergo mandatory human review and operational verification via official system channels before final dispatch.
